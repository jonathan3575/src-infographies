Pour toi

Tout pour le bloc, sur une page

  • Axe 1 — Voie d'abord
    Postérieure : cure de hernie · libération · fixation · ostéotomie (ponte/OTP) · stab dynamique · vertébroplastie · Postérieure mini-invasive : endo UBE/Mono · percutanée · TLIF · navigation · Antérieure : ALIF 1 niv · ALIF 2 niv · prothèse · hybride · autre — côté G/D · Latérale : LLIF · XLIF · corporectomie — côté G/D · Abord combiné : O/N + séquence (ANT/POST, POST/ANT, LAT/POST, ANT/LAT, POST/ANT/POST) + date 2e temps si différé
  • Axe 2 — Niveaux instrumentés
    Postérieur : sup L5→T12 / inf S1→L1 ou Bassin · Latéral : sup L1→L5 / inf L2→S1 ou Iliaque · Antérieur : L5S1 → L1L2
  • Axe 3 — Matériel
    Vis · cages · plaques · prothèses · ciment · Préciser le matériel selon ton protocole habituel.
  • Axe 4 — Contexte & séjour
    Chir sur région déjà opérée : O/N → si OUI : type (HD/libé, arthrodèse post/ant, autre) + niveau + année + commentaire · Type de séjour : hospitalisation traditionnelle / ambulatoire · Date d'intervention : libre
Pourquoi ça compte

Cette fiche → dossier de prog chir

  • Le A4 doit être scannable en 10 secondes par secrétaire + chir.
  • Voie d'abord + niveaux + matériel + contexte : rien ne manque, rien ne traîne.
  • Scoliose : hors 5L, réservée à la série scoliose à venir.
  • Une fois cette case complète, la programmation peut partir au bloc.
